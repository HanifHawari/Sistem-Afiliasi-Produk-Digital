# Sistem Afiliasi Produk Digital

Platform afiliasi untuk produk digital: affiliator membagikan link referral, sistem mencatat klik & penjualan, lalu menghitung komisi.

## Pembagian Tugas
| Branch | Fitur | PIC |
|---|---|---|
| `feature/admin-dashboard` | Kelola produk & komisi, afiliator, QRIS & rekening, verifikasi pembayaran, pencairan komisi, laporan penjualan | Muhammad Hanif Hawari |
| `feature/affiliate-dashboard` | Registrasi & login afiliator, katalog produk & komisi, link referral, materi promosi, statistik klik/penjualan/saldo, pengajuan pencairan | Muhammad Hanif Hawari |
| `feature/storefront-checkout` | Halaman produk untuk customer, checkout, pembayaran QRIS/transfer, upload bukti bayar, pengiriman produk digital | Muhammad Hanif Hawari |
| `feature/referral-tracking` | Tracking link referral & kode khusus, pencatatan klik, perhitungan komisi otomatis | Muhammad Hanif Hawari |
